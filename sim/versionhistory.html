CAN Bus Simulator - Version History

Version Date Changes to previous version
0.2.0 2026-10-31 New page layout.
  • Setup overview: both nodes with CAN controller, transceiver, delays and CAN bus
  • Configuration view (hide/show) per node, laid out as in the XL Bit Timing Configurator, plus transceiver, channel and frame inputs
  • Transceiver and channel parameters per node; t_cable as bus parameter
  • Node 2: delay transmission start (idle, hard sync on SOF)
  • Copy Node 1 config button
  • "Copy link with settings" button: shares all user parameters via the URL
0.1.0 2026-10-27 Initial development version.
  • Two-node CAN XL bus simulation (wired-AND bus model)
  • Configurable bit timing (arbitration and data phase), clock tolerance and TMS per node
  • Arbitration resolution and bit monitoring
  • PWM encoding of the data phase on TX_CC
  • Transceiver mode state machine (SIC / FAST_TX / FAST_RX)
  • Channel and transceiver delays and rising-edge asymmetries
  • SVG visualization of TX_CC, TX_bus, RX_CC, sample points and transceiver states
