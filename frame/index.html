Help: How to use the CAN MAC Frame Generator?

This tool generates the bit-level waveform of a valid MAC (Medium Access Control, OSI Layer 2) frame for CAN CC, CAN FD, or CAN XL. Therefore it calculates the CRC, inserts stuff bits (dynamic and fixed) and shows all fields and phases of the frame graphically.

Step by Step

  1. Select the "Frame Type" (CAN XL, CAN FD, ...).
  2. Enter the frame content: ID, DLC, control bits (e.g. BRS, ESI), for CAN XL additionally SDT, VCID and AF, and the data bytes in hex (e.g. "DE AD BE EF").
  3. Select the value of the ACK slot: 1 (no ACK) or 0 (ACK received).
  4. Press the button "Show Frame" to generate the waveform. Done

Display Options

  • Use the checkboxes in the header of the "Generated CAN Frame" pane to change the visualization.
  • "Arb-bits longer" draws the bits of the arbitration phase wider than the bits of the data phase.
  • The switch "Real Arb/Data bit ratio" scales the bit widths according to real bit rates. Enter the bit rate and sample point (SP) of the arbitration phase and (for CAN FD/XL) the data phase, then press "Show Frame" again.

Export & information

  • SVG / PNG: the waveform as vector graphic or image, e.g. for documentation.
  • CSV: list of all bits with bit value, bit name, element name and field name.
  • VHDL: a frame generator entity and testbench that drives the frame on a signal. Only available when "Real Arb/Data bit ratio" is enabled, because real bit times are required.
  • Below the waveform, "Frame Information" shows details of the generated frame (e.g. calculated CRC values and frame length).

Quick Try

Select a frame type, choose an entry in "Example" and press "Load" to fill the input fields and the frame is shown.
